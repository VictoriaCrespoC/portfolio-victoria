HTML

Guía rápida para escribir HTML moderno y semántico: estructura, meta, texto, enlaces, listas, multimedia, tablas, formularios, accesibilidad y buenas prácticas

Estructura básica


        <!DOCTYPE html>
        <html lang="es">
             <head>
                 <!-- Codificación de caracteres -->
                 <meta charset="UTF-8">

                 <!-- Configuración responsive -->
                 <meta name="viewport" content="width=device-width, initial-scale=1.0">
                 
                 <!-- Título y descripción -->
                 <title>Título</title>
                 <meta name="description" content="Descripción">

             </head>
             <body>
                 <main>Contenido</main>
             </body>
        </html>
  • DOCTYPE primero.
  • meta charset lo más arriba posible.
  • viewport para responsive.

Open Graph

Open Graph es un conjunto de metadatos que permite controlar cómo se presenta una página cuando se comparte en redes sociales.


                 <!-- Open Graph: previsualización en redes sociales -->
                 <meta property="og:title" content="Título en redes">
                 <meta property="og:description" content="Descripción para redes">
                 <meta property="og:image" content="URL_DE_LA_IMAGEN">
             </head>
             <body>
                 <main>Contenido</main>
             </body>
        </html>
