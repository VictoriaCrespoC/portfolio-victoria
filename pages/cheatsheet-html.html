HTML

Guía de referencia de HTML5 con ejemplos prácticos sobre estructura, etiquetas semánticas, texto, enlaces, listas, formularios y contenido multimedia.

Estructura básica


        <!DOCTYPE html>
        <html lang="es">
             <head>
                 <!-- Codificación de caracteres -->
                 <meta charset="UTF-8">

                 <!-- Configuración responsive -->
                 <meta name="viewport" content="width=device-width, initial-scale=1.0">
                 
                 <!-- Título y descripción -->
                 <title>Título</title>
                 <meta name="description" content="Descripción">

             </head>
             <body>
                 <main>Contenido</main>
             </body>
        </html>
  • DOCTYPE indica al navegador que el documento utiliza HTML5 y permite interpretarlo en modo estándar.
  • meta charset establece la codificación de caracteres para mostrar correctamente letras, tildes y símbolos.
  • viewport adapta la escala y el ancho de la página al dispositivo para facilitar el diseño responsive.

Open Graph

Open Graph es un conjunto de metadatos que permite controlar cómo se presenta una página cuando se comparte en redes sociales.


                 <!-- Open Graph: previsualización en redes sociales -->
                 <meta property="og:title" content="Título en redes">
                 <meta property="og:description" content="Descripción para redes">
                 <meta property="og:image" content="URL_DE_LA_IMAGEN">
             </head>
             <body>
                 <main>Contenido</main>
             </body>
        </html>

Enlaces externos y scripts

Permiten conectar el documento HTML con archivos externos, como hojas de estilos CSS y módulos JavaScript


        <head>
             <!-- Hoja de estilos externa -->
             <link rel="stylesheet" href="styles.css">

             <!-- Módulo JavaScript ES6 -->
             <script type="module" src="./js/main.js"></script>
        </head>

Maquetación semántica (HTML5)

Las etiquetas semánticas describen la función del contenido, mejorando la accesibilidad (A11y) y el posicionamiento en buscadores (SEO)

El <body> se divide en tres partes: <header>, <main> y <footer>

<header>

Cabecera principal del sitio o de una sección


        <header> <
             <nav> <!-- Bloque de enlaces de navegación principal -->
                  <a href="/">Inicio</a>
                  <a href="/proyectos">Proyectos</a>
             </nav>
        </header>

<main>

Contenido principal y único del documento


        <main> <
             <section> <!-- Agrupación temática de contenido -->
                  <h2>Sección Temática</h2>
                  <p>Contenido agrupado.</p>
             </section>

             <article> <!-- Contenido independiente y reutilizable -->
                   <h2>Título del Artículo</h2>
                   <p>Texto del artículo.</p>
             </article>

             <aside> <!-- Contenido secundario o relacionado -->
                   <h3>Relacionado</h3>
             </aside>
        </main>

<footer>

Pie de página


        <footer> <
             <small>© 2026 Mi Portfolio</small>
        </footer>

Encabezados y formato de texto

Los encabezados organizan jerárquicamente el contenido, mientras que las etiquetas de formato permiten destacar la importancia y el énfasis del texto.


        <h1>Título principal</h1>
        <h2>Título de sección</h2>
        <h3>Subsección</h3>
        <h4>Apartado</h4>
        <h5>Subapartado</h5>
        <h6>Nivel más específico</h6>

        <p>
            Texto con <strong>importancia clave</strong> y <em>énfasis</em>.
        </p>

Usa h1 una vez por página y respeta la jerarquía.

Formularios y accesibilidad

Los formularios permiten recoger información del usuario e interactuar con el servidor mediante diferentes campos de entrada.


        <form action="/enviar" method="POST">
              <!-- Campo de texto -->
              <label for="username">Nombre de usuario:</label>
              <input id="username" name="username" type="text" placeholder="Tu nombre" required>

              <!-- Campo de correo electrónico -->
              <label for="email">Correo electrónico:</label>
              <input id="email" name="email" type="email" required>

              <!-- Campo numérico con límites -->
              <label for="age">Edad:</label>
              <input id="age" name="age" type="number" min="18" max="99">

              <!-- Menú desplegable -->
              <label for="country">País:</label>
              <select id="country" name="country">
                    <option value="es">España</option>
              </select>

              <!-- Área de texto -->
              <label for="msg">Mensaje:</label>
              <textarea id="msg" name="msg" rows="4"></textarea>

              <!-- Botón de envío -->
              <button type="submit">Enviar</button>
        </form>

Atributos globales y buenas prácticas

Los atributos globales permiten identificar elementos, aplicar estilos, almacenar datos personalizados y mejorar la accesibilidad de los documentos HTML.

Identificador único: id


        <section id="proyectos">
              Contenido de la sección
        </section>

Identificador reutilizable: class


        <div class="card">Tarjeta 1</div>
        <div class="card">Tarjeta 2</div>

Almacenamiento de datos personalizados (data)


        <button data-plan="pro">Seleccionar plan</button>

Etiqueta accesible (aria-label)


        <button aria-label="Cerrar menú">×</button>

Listas HTML

Las listas permiten organizar y presentar información agrupada mediante elementos ordenados o desordenados.


        <!-- Lista desordenada -->
        <ul>
               <li>HTML</li>
               <li>CSS</li>
               <li>JavaScript</li>
        </ul>

        <!-- Lista ordenada -->
        <ol>
               <li>Crear la estructura HTML</li>
               <li>Añadir los estilos CSS</li>
               <li>Incorporar JavaScript</li>
        </ol>

Imágenes y elementos multimedia

HTML permite incorporar imágenes, audio, vídeo y contenido externo para enriquecer la experiencia del usuario.


        <!-- Imagen accesible -->
        <img src="img/logo.png" alt="Logotipo de la web">

        <!-- Imagen con pie de foto -->
        <figure>
               <img src="foto.jpg" alt="Atardecer en la costa">
               <figcaption>Atardecer en la costa.</figcaption>
        </figure>

        <!-- Audio -->
        <audio controls src="pista.mp3"></audio>

        <!-- Vídeo -->
        <video controls width="480" src="demo.mp4"></video>

        <!-- Contenido externo incrustado -->
        <iframe src="https://www.youtube.com/embed/ID"
               title="Reproductor de vídeo"></iframe>

Mejores prácticas

Recomendaciones para escribir código HTML limpio, accesible, seguro y optimizado.

  • HTML válido: utiliza una estructura correcta y una indentación consistente.
  • Accesibilidad: incluye atributos alt descriptivos en las imágenes.
  • Seguridad: utiliza rel="noopener noreferrer" en enlaces que abren pestañas nuevas.
  • Rendimiento: utiliza loading="lazy" en imágenes que no necesitan cargarse inmediatamente.
  • Validación: comprueba el código con herramientas como HTML Validator y revisa la accesibilidad.
